# Frontend (packages/frontend)

React + TypeScript app, built with Vite.

- Run dev server: `npm run dev`
- Build: `npm run build`
- No test suite yet — when adding one, use Vitest + React Testing Library, colocated with the component under `src/`.

See the repo-root `.claude/rules/react-ui.md` for component conventions
(loads automatically when you touch `.ts`/`.tsx` files here).
